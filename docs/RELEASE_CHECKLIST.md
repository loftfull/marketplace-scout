# Release checklist

- [ ] Lint, types, deterministic tests, target build and audits pass on the final commit.
- [ ] CI Windows/Linux result inspected; external billing/runner blocks reported separately.
- [ ] Independent critic closes false-verification/security findings.
- [ ] UI inspected on desktop/mobile; no demo offers.
- [ ] Live source outcomes and card stages saved with time, URLs, product/variant IDs and no personal sessions.
- [ ] Positive live price/seller/spec evidence obtained before claiming live VERIFIED support is accepted.
- [ ] History backup and rollback runbook available.
- [ ] No secrets/profile/runtime/cache/test-only synthetic offers in commits.

Current local engineering checks and a blocked acceptance run do not authorize public release. PR stays unmerged. Follow docs/RUNBOOK.md for restart/rollback. Product identity or provider changes require a new approved plan.
