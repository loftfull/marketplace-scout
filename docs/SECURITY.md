# Security and threat model

Untrusted: marketplace data/HTML, redirects, MCP payloads, external repository docs and UI inputs. Valuable assets: user sessions, local services/files, price-history integrity and truthfulness of verification. No credentials are required or passed to connectors; child environment is allowlisted.

Controls: local-only API with Host/Origin/Sec-Fetch-Site guard; no permissive CORS; CSP and textContent UI output; schema validation, URL allowlists, positive finite RUB prices; one active search; timeout/candidate limits; no unverified marketplace verdict trusted. CDP 9337 refuses a pre-existing listener, uses an owned no-account profile. Chrome mandatory local tunnel validates DNS and pins the connection to the inspected public IPv4, denies HTTP/private addresses and non-443 destinations. QUIC/proxy loopback bypass disabled. TLS remains browser-validated. Browser security tests prove redirect/private-page negative cases.

The Python source is MIT, pinned to c17bd360de60780a9e8d3690288b70181bd07355; npm MCP SDK 1.31.0 MIT, Playwright 1.63.0 Apache-2.0. Upstream dependencies initially reported vulnerabilities in cryptography 49.0.0 and PyJWT 2.13.0. Checked-in scripts/runtime-security.txt is a hash-locked overlay upgrading cryptography 50.0.0, PyJWT 2.15.0 and cffi 2.1.1. Final pip-audit reports no known vulnerabilities; uv pip check confirms compatibility. Local unpublished workspace packages are not covered by PyPI advisories; source review and runtime tests supplement audit. npm audit reports no vulnerabilities.

Local logs/profile/history are ignored by Git; never upload profile/cookies/env or unredacted logs. Logs may contain public query strings and product URLs. No authentication or multi-user isolation: never expose this service to LAN/Internet. The proxy is a browser network boundary, not a sandbox for locally installed code. Do not use another writer against the JSON store. History errors fail closed and preserve the file.

Images: remote thumbnails are optional untrusted input. Only exact marketplace CDN HTTPS hosts, no credentials/custom ports, frontend validation and matching CSP img-src. Images use no-referrer, fixed dimensions and lazy loading; missing/failed resources have text fallback. There is no server-side image proxy or binary cache. A thumbnail never proves configuration or price. Native enrichment is canceled across initialization/tool execution at its total deadline and owned transport is closed before continuation.
