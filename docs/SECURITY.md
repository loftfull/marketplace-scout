# Security and threat model

Research extension: fixed provider/tool registry and strict field allowlists; no command/URL passthrough. Maximum three comparison IDs, bounded counts/deadlines and256KiB sanitized payload. Buyer identity/contact fields are dropped and email/phone patterns redacted; data is textContent-only and never executable or automatically linked. Search and research share a lock through cleanup. Ozon process-wide block latch survives upstream optional catches and rejects partial MCP results; per-source research cooldown prevents immediate new-process retries. Anonymous observations never grant VERIFIED or write price history. Python child processes run UTF-8 explicitly. Tabler assets are pinned, local, MIT-attributed and retain existing CSP; no remote theme scripts or fonts.

Untrusted: marketplace data/HTML, redirects, MCP payloads, external repository docs and UI inputs. Valuable assets: user sessions, local services/files, price-history integrity and truthfulness of verification. No credentials are required or passed to connectors; child environment is allowlisted.

City/provider extension: city IDs are allowlisted and snapshotted; observed region cannot be supplied by the request itself. Market transport imports a pinned MIT parser but replaces its HTTP lifecycle with fixed-host public-DNS-pinned TLS, bounded body/deadline and terminal redirects/denials with persistent cooldown. WB geo uses a fixed host, public pinned DNS, no redirects and a64KiB/12s boundary; city/coordinate/destination association is mandatory. WB adapter denies HTTP blocks and HTML walls before legacy fallback. This is application-level containment, not an OS sandbox for imported Python. No upstream code is silently updated. See CONNECTORS.md for provenance and remaining live-schema uncertainty.

Controls: local-only API with Host/Origin/Sec-Fetch-Site guard; no permissive CORS; CSP and textContent UI output; schema validation, URL allowlists, positive finite RUB prices; one active search; timeout/candidate limits; no unverified marketplace verdict trusted. CDP 9337 refuses a pre-existing listener, uses an owned no-account profile. Chrome mandatory local tunnel validates DNS and pins the connection to the inspected public IPv4, denies HTTP/private addresses and non-443 destinations. QUIC/proxy loopback bypass disabled. TLS remains browser-validated. Browser security tests prove redirect/private-page negative cases.

The ru Python source is MIT, pinned to c17bd360de60780a9e8d3690288b70181bd07355; npm MCP SDK 1.31.0 MIT, Playwright 1.63.0 Apache-2.0. Upstream dependencies initially reported vulnerabilities in cryptography 49.0.0 and PyJWT 2.13.0. Checked-in scripts/runtime-security.txt is a hash-locked overlay upgrading cryptography50/PyJWT2.15/cffi2.1.1. Final pip-audit reports no known vulnerabilities; uv pip check confirms compatibility. Local unpublished workspace packages are not covered by PyPI advisories; source review and runtime tests supplement audit. npm audit reports no vulnerabilities.

Specialized source: SZhukovWork/ozon-mcp, MIT, pin414b3470ee6dd6f3197598b2c3c640d5d1601ef3. scripts/ozon-runtime.txt locks32 dependencies with hashes, including MCP2.2.0 and Playwright1.63.0. Separate venv avoids ru dependency conflicts. No upstream code is copied into Scout; the adapter imports pinned source. Native responses are untrusted: exact SKU/URL/Market variant joins, bounded fields, finite positive prices, escaped DOM text. Seller legal addresses/registration details and review bodies are discarded. Native results cannot promote current prices. Python code is trusted installed code, not OS-sandboxed; the mandatory proxy protects browser traffic, not arbitrary Python sockets. New bridge never uses the upstream launch/disguise/download/session-renewal methods or saved account state. Lock audit reported zero known advisories; this is not a guarantee against unknown vulnerabilities.

Local logs/profile/history are ignored by Git; never upload profile/cookies/env or unredacted logs. Logs may contain public query strings and product URLs. No authentication or multi-user isolation: never expose this service to LAN/Internet. The proxy is a browser network boundary, not a sandbox for locally installed code. Do not use another writer against the JSON store. History errors fail closed and preserve the file.

Images: remote thumbnails are optional untrusted input. Only exact marketplace CDN HTTPS hosts, no credentials/custom ports, frontend validation and matching CSP img-src. Images use no-referrer, fixed dimensions and lazy loading; missing/failed resources have text fallback. There is no server-side image proxy or binary cache. A thumbnail never proves configuration or price. Native enrichment is canceled across initialization/tool execution at its total deadline and owned transport is closed before continuation.
